自動化規則

  • 每日 18:17（Asia/Taipei）檢查 DGBAS、MOEA、RIS、NDC、SEGIS 與決策輸入官方來源。
  • 每日 10:17 同步 Consultant_System 的研究 metadata、CSV 與 SQLite snapshot。
  • 新官方資料先解析、revision diff、值域與 freshness 驗證；失敗時保留上一版。
  • 每次官方資料更新重算 Cycle Score、Growth Persistence、Domestic Demand、Financial Conditions 與摘要。
  • 顧問研究與 SEGIS structural context 永遠不直接參與 deterministic Score。
  • 所有 Score 缺值時重新正規化權重並降低 Confidence，不把缺值當 0。
  • 資料通過驗證後自動 commit 到 main 並重新發布 Pages。
  • 關鍵來源更新失敗時，自動建立或更新 GitHub Issue；恢復後自動關閉。
